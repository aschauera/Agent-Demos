# Agent Demos & Samples

Demonstrations and samples for Power Platform and Azure-based agents and autonomous agents.

## 📁 Project Structure

### Core Agent Implementations

- **[AdvisorWebAgent](./AdvisorWebAgent/)** - Web-based advisor agent with chat interface
- **[AutonomousPlantVisitAgent](./AutonomousPlantVisitAgent/)** - Autonomous agent for plant visits
- **[OesiChat](./OesiChat/)** - Chat application with dam and imaging resources
- **[PhoneAgent](./PhoneAgent/)** - Phone-based agent using Call Automation
- **[VoiceAgentSample](./VoiceAgentSample/)** - Voice agent implementation with Bot Service
- **[VoiceWebChat](./VoiceWebChat/)** - Voice-enabled web chat interface

### Web Services & APIs

- **[demowebservices/MockContractWebService](./demowebservices/MockContractWebService/)** - Mock web service for contract operations
- **[Custom WebService Agent](./Custom%20WebService%20Agent/)** - Custom agent for web service integration
- **[aurea-crm-connector](./aurea-crm-connector/)** - Configurable Power Platform connector and on-premises session adapter for generated Aurea CRM REST services

## 🚀 Getting Started

Each project folder contains its own README with specific setup and deployment instructions. Start by reviewing the README in the agent you're interested in.

## 📋 Prerequisites

- Azure account
- Appropriate Azure services (Bot Service, Copilot Studio, AI Foundry)
- Required SDKs and tools as specified per project
